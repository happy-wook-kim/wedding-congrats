# 배경음

`bgm.mp3` — 파헬벨 카논, 피아노 독주

- 출처: Internet Archive `PachelbelsCanoninD` (Canon_in_D_Piano.mp3, 320kbps 원본)
- 라이선스: **퍼블릭 도메인** (CC Public Domain Dedication)
- 가공: 원본 7분 42초 중 **2:30~5:30 구간**만 사용
  - 원본은 처음부터 끝까지 서서히 커지는 구조라 시작이 평균 -47dB로 거의 안 들림
  - 가장 충실한 구간을 잘라 loudnorm(I=-16 LUFS)으로 정규화 → 평균 -18dB
  - 루프 이음새를 부드럽게 하려고 앞뒤 1초 페이드
  - 160kbps, 3분, 4.3MB

교체할 때는 라이선스를 반드시 확인한다. 곡이 퍼블릭 도메인이어도
연주 녹음에는 별도 권리가 있다.
